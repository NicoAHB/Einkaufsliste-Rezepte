# Händlerlogos und Angebotslinks

Stand: 29.10.2026. Katalog: `../../store-catalog.js` (Deutschland).
Die kleinen Logos/Favicons werden lokal ausgeliefert, auch im Offline-Paket.
Kein Hotlink, kein Logo-Dienst und keine Verbindung zum Händler beim Anzeigen.
PNG-Dateien wurden auf höchstens 192 Pixel verkleinert, SVG unverändert übernommen.

Die Marken gehören ihren jeweiligen Inhabern. Die Abbildungen dienen der Identifikation der Geschäfte;
die App ist kein offizielles Angebot dieser Händler. Die Quellenliste erteilt keine Markenlizenz.
Vor einer kommerziellen App-Store-Veröffentlichung die Nutzungsrechte der Markenabbildungen klären.

Angebotsseiten können eine Filial-/PLZ-Auswahl verlangen. Bei dm verlinkt der Katalog auf
Neuheiten & Aktionen statt auf einen nicht vorhandenen allgemeinen Wochenprospekt.
`nah & gut` nutzt die EDEKA-Angebotssuche; dort den eigenen Markt wählen.
Eigene Links überschreiben die Katalog-Voreinstellung. ALDI, Netto und famila ohne Regionalangabe
bekommen keinen geratenen Link; im Geschäftsformular den passenden Händler auswählen.
